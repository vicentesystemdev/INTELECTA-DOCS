# Ficha del Proyecto INTELECTA

## Información Académica Oficial

*   **Título del Proyecto:** SISTEMA WEB DE EVALUACIÓN Y SEGUIMIENTO ACADÉMICO PARA OPTIMIZAR EL MONITOREO DEL DESEMPEÑO DE POSTULANTES PREUNIVERSITARIOS MEDIANTE LEARNING ANALYTICS, TEORÍA DE RESPUESTA AL ÍTEM Y MODELOS PREDICTIVOS.

## Ficha Técnica del Sistema

*   **Nombre del Sistema:** INTELECTA.
*   **Tipo de Aplicación:** Plataforma Web Operativa y de Seguimiento Académico.
*   **Framework Principal:** Laravel 13 (PHP 8.3).
*   **Frontend:** React (Inertia.js + Tailwind CSS).
*   **Base de Datos:** PostgreSQL (con soporte para transacciones y soft deletes).
*   **Motor de Caché y Colas:** Redis.
*   **Esquema de Autorización:** Spatie Laravel Permission (Roles y Permisos).
*   **Objetivo de Negocio:** Optimizar la toma de decisiones curriculares y tutoriales de los coordinadores y tutores en el proceso de nivelación preuniversitaria, identificando riesgos de rendimiento y proyectando áreas de mejora.
